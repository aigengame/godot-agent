## Design reference

#1109 (native parent for scope/progress; only Blocked by defines execution prerequisites).

## What to build

The local Windows e2e selection reaches product behavior instead of Unix-only fixture failures. Port demonstrated temporary-directory, environment, path, filesystem and capture assumptions without weakening behavior.

## Acceptance criteria

- [ ] Per-run temporary roots and Windows application-data setup replace /tmp and HOME-only assumptions. A full selected run has no fixture setup errors or hidden reader-thread decode exceptions caused by those assumptions.
- [ ] Compare equivalent paths semantically, use Windows-legal filenames, escape generated GDScript paths, and count spill bytes from raw bytes rather than newline-normalized text.
- [ ] Permissions are tested as actual permissions, not Windows chmod assumptions. Junction cases are used only where semantically equivalent; file-symlink privilege skips remain explicit and meaningful containment assertions remain.
- [ ] Record selected/passed/failed/setup-error/skipped counts, warnings and reasons separately from the original audit. Product failures owned by other tasks stay visible as failures.
- [ ] Relevant Unix fixture behavior is retained.

## Scope boundary

No Windows CI, test-directory overhaul, suite-wide user-data/UTF-8 override or weakening of production containment rules.

## Delivery constraints

Follow the overall design reference and ADR-0045 at the merged core-layering revision. Add small adapters at existing seams; keep core closed, framework-free and process-entry-free, and gda-mcp on the public CLI ABI. Preserve the existing import-direction gate, RunResult, EngineSession.request, Value projection and completed-run settlement.

Use UTF-8 at the source. Windows CI, code-page compatibility, platform/provider registries, broad core refactoring and Windows handler copies are excluded. Update affected schema/help/docs/configuration/bundled skill with the behavior. Save commands, environment, exact test counts, skip reasons and raw results. Real public-channel evidence and relevant Unix regression checks are required; mocks alone do not establish integration.
