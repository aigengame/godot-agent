## Design reference

#1109 (native parent for scope/progress; only Blocked by defines execution prerequisites).

## What to build

A native non-UTF-8 Windows caller can start gda/gda-mcp and exchange schema, Chinese and emoji without an encoding environment workaround. Set UTF-8 before parsing/help/error emission; preserve opaque engine bytes and CRLF.

## Acceptance criteria

- [ ] With Python UTF-8 mode disabled and no PYTHONUTF8 workaround, installed console and module entry forms emit parseable schema and structured success/error payloads; help and early errors also work.
- [ ] A real MCP process starts/discovers tools; Chinese/emoji stdin and output round-trip. A successful scene mutation does not fail only while rendering its result.
- [ ] Relevant JSON/file/capture I/O uses explicit UTF-8; raw spill bytes and byte counts stay exact. Do not globally enable UTF-8 in tests to mask the defect.
- [ ] Use a separate CLI console wrapper, not the existing Typer callback. MCP uses a few equivalent stdlib calls or its own private helper, with no internal CLI/core imports or shared utility layer.
- [ ] Focused real entry checks and relevant Unix entry regressions pass.

## Scope boundary

No code-page guessing/conversion, CJK branch, chcp requirement, lossy fallback or import-time global stdio mutation.

## Delivery constraints

Follow the overall design reference and ADR-0045 at the merged core-layering revision. Add small adapters at existing seams; keep core closed, framework-free and process-entry-free, and gda-mcp on the public CLI ABI. Preserve the existing import-direction gate, RunResult, EngineSession.request, Value projection and completed-run settlement.

Use UTF-8 at the source. Windows CI, code-page compatibility, platform/provider registries, broad core refactoring and Windows handler copies are excluded. Update affected schema/help/docs/configuration/bundled skill with the behavior. Save commands, environment, exact test counts, skip reasons and raw results. Real public-channel evidence and relevant Unix regression checks are required; mocks alone do not establish integration.

## Blocked by

None — can start immediately.
