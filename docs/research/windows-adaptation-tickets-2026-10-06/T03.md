## Design reference

#1109 (native parent for scope/progress; only Blocked by defines execution prerequisites).

## What to build

A configured Windows MCP-to-gda-to-Godot call preserves both independent executable contracts: GDA_BIN overrides the command that invokes gda, while GDA_GODOT selects Godot. Keep Unix parsing and the macOS fallback on macOS only.

## Acceptance criteria

- [ ] Godot resolution precedence is --godot > GDA_GODOT > bounded PATH candidates > the applicable platform fallback. Windows does not default to a macOS app path.
- [ ] The separate MCP GDA_BIN override preserves spaces/quotes/backslashes and ordered gda arguments using native parsing; when unset it retains [sys.executable, -m, gda], never a PATH lookup of gda. Real MCP startup and a project operation work with the override.
- [ ] Verify explicit Godot GUI/console paths, missing binaries and version floors. Godot resolution does not read GDA_BIN.
- [ ] PowerShell, escaped MCP JSON and GUI-agent PATH guidance agree with the resolver; no machine-specific versioned drive path is a code default.
- [ ] Relevant Unix resolution/argv checks pass.

## Scope boundary

No shell execution, arbitrary directory scan, provider registry or broad launch rewrite.

## Delivery constraints

Follow the overall design reference and ADR-0045 at the merged core-layering revision. Add small adapters at existing seams; keep core closed, framework-free and process-entry-free, and gda-mcp on the public CLI ABI. Preserve the existing import-direction gate, RunResult, EngineSession.request, Value projection and completed-run settlement.

Use UTF-8 at the source. Windows CI, code-page compatibility, platform/provider registries, broad core refactoring and Windows handler copies are excluded. Update affected schema/help/docs/configuration/bundled skill with the behavior. Save commands, environment, exact test counts, skip reasons and raw results. Real public-channel evidence and relevant Unix regression checks are required; mocks alone do not establish integration.
