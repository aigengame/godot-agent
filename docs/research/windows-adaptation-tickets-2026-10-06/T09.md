## Design reference

#1109 (native parent for scope/progress; only Blocked by defines execution prerequisites).

## What to build

A real CLI/MCP caller completes wait-ready -> game tree/get -> stop. Reuse recipes/framing/handlers; add TCP readiness/complete-frame receive and Windows Job ownership.

## Acceptance criteria

- [ ] Reach the requested scene with Live 4.6+ and original token/scene verification. A wrong harness peer is rejected and the next accepted within the same launch deadline.
- [ ] Use StreamPeerSocket, asynchronous connection readiness and complete-frame buffering. Fragmented input leaves game ticks running; verify large replies/disconnects before adding a send queue.
- [ ] A Job owns the real engine tree before descendants start. Verify a controlled worker gate or narrower equivalent with real GUI/console Godot paths; preserve poll/wait without private Popen handles or PID/name scanning.
- [ ] Worker startup is not engine startup: propagate actual Godot spawn success/failure, launch exception and full Windows exit status within the original deadline, rather than hiding access-denied/invalid-exe failures as handshake timeouts.
- [ ] Stop, daemon crash, timeout and replacement leave no owned descendants even after leader exit, and preserve unrelated processes. Retain ownership handles until retirement; add no Windows timeout/grace budget.
- [ ] Preserve EngineSession.request, session identity, single-writer/frame-coherent state and diagnostics. Document forced-stop flush limits; narrowly amend ADR-0017.
- [ ] Open only verified headless routes in the existing predicate, keep windowed refusal explicit, and pass relevant Unix lifecycle/protocol and import-direction checks.

## Scope boundary

No generic RPC/process-manager framework, handler rewrite, public RunResult redesign or older-engine compatibility project.

## Delivery constraints

Follow the overall design reference and ADR-0045 at the merged core-layering revision. Add small adapters at existing seams; keep core closed, framework-free and process-entry-free, and gda-mcp on the public CLI ABI. Preserve the existing import-direction gate, RunResult, EngineSession.request, Value projection and completed-run settlement.

Use UTF-8 at the source. Windows CI, code-page compatibility, platform/provider registries, broad core refactoring and Windows handler copies are excluded. Update affected schema/help/docs/configuration/bundled skill with the behavior. Save commands, environment, exact test counts, skip reasons and raw results. Real public-channel evidence and relevant Unix regression checks are required; mocks alone do not establish integration.
